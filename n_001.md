**Bash Introduction – Complete Notes**

### What is Bash?

Bash is used to run commands and write scripts on Unix/Linux systems.

Bash is the default shell on most Linux and macOS systems.

---

### Why Learn Bash?

Bash is a powerful tool for developers and system administrators.

Understanding and mastering Bash is important for working in Unix/Linux environments.

---

### Shell vs. Bash Shell

A “Shell” is any command-line tool.  
“Bash shell” specifically means the **Bourne Again SHell**.

Because of its popularity, Bash is often what people think of when they say “shell.”

---

### History of Bash

Bash was developed in **1989** by **Brian Fox**.

It was created as a free replacement for the original Bourne shell.  
It quickly became the default shell for GNU and many Linux systems.

Over time, Bash added features from other shells (such as the Korn shell and C shell) and became a very versatile tool for command-line users.

---

### Practical Uses of Bash

**System administrators** use Bash to:
- Automate tasks
- Perform system operations
- Process data

**Developers** use Bash for:
- Build automation
- Testing
- Deployment
- Data processing and manipulation
